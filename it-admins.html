SlidePace for IT administrators

SlidePace is a Chrome extension that shows a timer on top of Google Slides™ slideshows. This page gives school and company IT teams the facts needed to allow it: what it may access, what it sends, and how to deploy it. The permissions below come from the manifest of the published version (1.2.0).

Extension

  • Chrome Web Store ID: dchbmbjjgcdjkhkkmebpnbhgegchobca (listing).
  • Publisher: PPCC Studio (EURL PIERRE-PHILIPPE CONSEIL & COACHING, France). Manifest V3; no remote code is loaded or run.
  • Account: none, for the free version and for SlidePace Pro.

Permissions

  • storage: keeps the user’s settings in the browser only (local storage of the extension).
  • scripting, limited to the address below: puts the timer back in Google Slides tabs that were already open when the extension is installed or updated.
  • Site access: https://docs.google.com/presentation/* only, to display the timer during the slideshow. SlidePace does not read the content of the slides.
  • Optional site access https://api.slidepace.com/*: requested only when a SlidePace Pro license is activated; the user can decline it. It is used to check the license.
  • Messages accepted from https://slidepace.com/* only (externally_connectable): the license page can send a license key to the extension, after the user clicks “Activate in SlidePace”.

Chrome shows one warning at installation: “Read and change your data on docs.google.com”.

What is sent over the network

  • Free version: nothing. No analytics, no tracking, no request to any server.
  • 30-day Pro trial: nothing is sent.
  • SlidePace Pro: about once a month, one request to https://api.slidepace.com with the license ID only — never the user’s name, email or the content of the presentations. Details: privacy policy.

Deployment on managed computers

  • Allow or force-install the extension with its ID in your Chrome management tools (for example the Google Admin console, or the ExtensionInstallForcelist and ExtensionSettings Chrome policies).
  • If your policies block site access, keep https://docs.google.com/presentation/* allowed for the extension: without it, the timer cannot appear.
  • For SlidePace Pro, also allow https://api.slidepace.com: if the license cannot be checked, Pro keeps working for at least 30 days, then may pause until a check succeeds (the free timer is never affected).
  • Microsoft Edge can install the extension from the Chrome Web Store; other Chromium-based browsers are not tested by us.
