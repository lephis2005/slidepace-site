IT 管理者向け SlidePace

SlidePace は、Google スライド™ のスライドショーの上にタイマーを表示する Chrome 拡張機能です。このページでは、学校や企業の IT 担当者が導入を許可するために必要な事実（アクセスできる範囲、送信する内容、導入方法）をまとめています。以下の権限は、公開中のバージョン（1.2.0）のマニフェストに基づいています。

拡張機能

  • Chrome ウェブストアの ID：dchbmbjjgcdjkhkkmebpnbhgegchobca（掲載ページ）
  • 提供元：PPCC Studio（EURL PIERRE-PHILIPPE CONSEIL & COACHING、フランス）。Manifest V3。外部のコードを読み込んだり実行したりすることはありません。
  • アカウント：無料版・SlidePace Pro とも不要です。

権限

  • storage：ユーザーの設定をブラウザ内（拡張機能のローカルストレージ）にのみ保存します。
  • scripting（下記のアドレスに限定）：拡張機能のインストール時・更新時に、すでに開いている Google スライドのタブにタイマーを表示し直すために使います。
  • サイトへのアクセス：https://docs.google.com/presentation/* のみ。スライドショー中にタイマーを表示するためです。SlidePace はスライドの内容を読み取りません。
  • https://api.slidepace.com/* への任意のアクセス：SlidePace Pro の利用者にだけ、操作したとき（ライセンスの有効化時、または後で「許可」や「今すぐ確認」を押したとき）に求められ、ユーザーは拒否できます。ライセンスの確認に使います。
  • https://slidepace.com/* からのメッセージのみ受け付けます（externally_connectable）。ライセンスページは、ユーザーが「Activate in SlidePace」ボタンをクリックした後に限り、ライセンスキーを拡張機能に送ることができます。

インストール時に Chrome が表示する警告は、docs.google.com 上のデータの読み取りと変更に関するもの 1 つだけです。

ネットワークで送信される内容

  • 無料版：何も送信しません。統計もトラッキングもなく、どのサーバーにもリクエストを送りません。
  • Pro の 30 日間無料体験：何も送信しません。
  • SlidePace Pro：およそ月に一度、ライセンス ID のみを付けて https://api.slidepace.com に 1 回リクエストを送ります。名前、メールアドレス、プレゼンテーションの内容は送りません。詳細はプライバシーポリシー（英語）をご覧ください（フランス語版が正文です：フランス語版）。

管理対象のパソコンへの導入

  • Chrome の管理ツール（たとえば Google 管理コンソール、または Chrome のポリシー ExtensionInstallForcelist と ExtensionSettings）で、ID を指定して拡張機能を許可または強制インストールしてください。
  • ポリシーでサイトへのアクセスを制限している場合は、この拡張機能に https://docs.google.com/presentation/* へのアクセスを許可してください。許可がないとタイマーを表示できません。
  • SlidePace Pro を使う場合は https://api.slidepace.com も許可してください。ライセンスを確認できない場合でも、Pro は少なくとも 30 日間は動作し、その後は確認が成功するまで一時停止することがあります（無料版のタイマーには影響しません）。
  • Microsoft Edge は Chrome ウェブストアから拡張機能をインストールできます。そのほかの Chromium ベースのブラウザは当方では未確認です。
