SlidePace pour les administrateurs informatiques

SlidePace est une extension Chrome qui affiche un minuteur par-dessus les diaporamas Google Slides™. Cette page donne aux équipes informatiques des établissements et des entreprises les informations utiles pour l’autoriser : ce à quoi elle peut accéder, ce qu’elle envoie et comment la déployer. Les autorisations ci-dessous viennent du manifeste de la version publiée (1.2.0).

L’extension

  • Identifiant du Chrome Web Store : dchbmbjjgcdjkhkkmebpnbhgegchobca (fiche).
  • Éditeur : PPCC Studio (EURL PIERRE-PHILIPPE CONSEIL & COACHING, France). Manifest V3 ; aucun code distant n’est chargé ni exécuté.
  • Compte : aucun, pour la version gratuite comme pour SlidePace Pro.

Autorisations

  • storage : garde les réglages de l’utilisateur dans le navigateur seulement (stockage local de l’extension).
  • scripting, limité à l’adresse ci-dessous : remet le minuteur dans les onglets Google Slides déjà ouverts à l’installation ou à la mise à jour de l’extension.
  • Accès aux sites : https://docs.google.com/presentation/* seulement, pour afficher le minuteur pendant le diaporama. SlidePace ne lit pas le contenu des diapositives.
  • Accès facultatif à https://api.slidepace.com/* : demandé seulement à l’activation d’une licence SlidePace Pro ; l’utilisateur peut le refuser. Il sert à vérifier la licence.
  • Messages acceptés depuis https://slidepace.com/* seulement (externally_connectable) : la page de licence peut envoyer une clé de licence à l’extension, après un clic de l’utilisateur sur « Activer dans SlidePace ».

Chrome affiche un seul avertissement à l’installation : « Lire et modifier vos données sur docs.google.com ».

Ce qui passe par le réseau

  • Version gratuite : rien. Ni statistiques, ni pistage, aucune requête vers un serveur.
  • Essai Pro de 30 jours : rien n’est envoyé.
  • SlidePace Pro : environ une fois par mois, une requête vers https://api.slidepace.com avec l’identifiant de licence seulement — jamais le nom, l’email ni le contenu des présentations. Détail : politique de confidentialité.

Déploiement sur des ordinateurs gérés

  • Autorisez ou installez d’office l’extension avec son identifiant dans vos outils de gestion de Chrome (par exemple la console d’administration Google, ou les règles Chrome ExtensionInstallForcelist et ExtensionSettings).
  • Si vos règles bloquent l’accès aux sites, gardez https://docs.google.com/presentation/* autorisé pour l’extension : sans lui, le minuteur ne peut pas s’afficher.
  • Pour SlidePace Pro, autorisez aussi https://api.slidepace.com : si la licence ne peut pas être vérifiée, Pro continue de fonctionner au moins 30 jours, puis peut se mettre en pause jusqu’à une vérification réussie (le minuteur gratuit n’est jamais concerné).
  • Microsoft Edge peut installer l’extension depuis le Chrome Web Store ; les autres navigateurs basés sur Chromium ne sont pas testés par nous.

Nous ne proposons ni bon de commande, ni licence multi-utilisateurs, ni licence de site. Pour toute question, écrivez à contact@slidepace.com.
